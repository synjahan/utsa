## Demonstrated here

- Actual MeTTa evaluation returns evidence-bearing typed relationships.
- The first regression persists an older offer in a completed process, then
  retrieves it from a fresh process when a new contribution arrives 21 days later
  by the test clock from another logical container.
- A manually specified cross-domain test distinguishes interest, capability fit,
  and an actionable candidate without assuming all three coincide.
- Both source permissions, destination, purpose, principal, freshness and current
  revisions gate inference. Separate recipient grants gate previews.
- Bilateral acceptance gates a still-undelivered introduction intent. Revocation
  and revision changes are rechecked before that intent can be returned.

The test logs in `evidence/` state the interpreter(s), executed commands, and actual
results. Passing fixtures demonstrate these code paths, not production deployment.

## Not yet established

- Exact replay of the original Sprint artifacts. These fixtures are synthetic
  reconstructions, with the 21-day gap specified by the current user request.
- Real Docker/container-network operation, distributed access controls, or
  permission to reuse old real offers for current contact.
- Hives integration, Omega plugin deployment, private message delivery, recipient
  identity resolution, or authority over host data.
- Full PLN truth-value inference, learned semantic bridges, inherited research
  corpora, autonomous agent execution, scheduling, attestation or reputation.
- Multi-user server authentication, adversarial infrastructure hardening,
  large-scale matching, backups, forensic erasure, or multi-region recovery.
